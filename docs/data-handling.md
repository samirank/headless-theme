# Data handling

- **Stored locally:** one WordPress option, `headless_frontend_url`, in the site's own database.
- **Sent to third parties:** nothing. Visitors are redirected to the configured frontend URL.
- **Personal data:** none collected by the theme. It enables anonymous REST comments; WordPress stores those under its own rules.
- **Export and deletion:** deleting the option or switching theme removes the theme's data.
- **Telemetry:** none.
- **Security:** see [SECURITY.md](../SECURITY.md).
