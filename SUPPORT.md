# Support

- **Where to get help:** [README.md](README.md) and [docs/runbook.md](docs/runbook.md); open an issue at https://github.com/samirank/headless-theme/issues.
- **What is supported:** the latest release on the latest WordPress 6.x with PHP 8.1 or newer. Older versions are not supported.
- **What to expect:** replies are best effort; this is a target, not a guarantee.
- **Out of scope:** custom development and the external frontend you redirect to.
- **Security issues:** do not post them here; follow [SECURITY.md](SECURITY.md).
