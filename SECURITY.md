# Security Policy

## Reporting

Use GitHub's private vulnerability reporting / Security Advisory flow when it is enabled for this repository. If that flow is unavailable, contact Samiran directly through an agreed private channel. Do not paste secrets, private keys, tokens, exploit credentials, dumps, or personal data into public GitHub issues, pull requests, logs, or screenshots.

## Handling

Security-impacting changes require human review. High-risk paths include GitHub workflows, Composer dependency files, environment examples, redirect behavior, REST API filters, and deployment configuration.

## Supported Scope

This repository stores source and documentation only. Production WordPress credentials, hosting credentials, and environment files must remain outside Git.
